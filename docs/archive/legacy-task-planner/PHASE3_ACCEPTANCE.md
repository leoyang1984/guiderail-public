# Phase 3：目标与阶段验收

实现版本 0.2.1，存储版本 3。Phase 4 白板尚未实施。

## 操作入口

- 计划顶部“编辑目标”：填写总目标及整体完成条件。
- “管理阶段”：新增、改名、上下排序；仅允许删除空阶段，且保留至少一个阶段。
- 新建步骤时选择阶段；已有步骤在详情中的“所属阶段”下拉框移动，追加到目标阶段末尾。步骤编号、当前状态、问题、消息来源均保留。
- 阶段内上下移动步骤；调整阶段顺序时，整个阶段的步骤随之移动。执行顺序按阶段及其内部步骤顺序排列。
- “复制整理计划提示词”：交给 ChatGPT 整理已有建议。粘贴整理结果到“粘贴计划并预览”，核对后追加。

## 导入范围

支持 `## 阶段标题`、`第一阶段：名称`；步骤支持顶层 `1. 标题`、`1、标题`、`- [ ] 标题`、`### 步骤标题`。代码块不拆步骤，缩进子列表保留为说明。

预览显示所有阶段和步骤，可展开详情。阶段下没有明确步骤的文字仅保留在导入原文中，不生成任务。模糊段落不自动推断。勾选“使用以上目标信息”才替换原计划对应目标字段；默认只追加阶段和步骤。

## 已完成验证

自动测试涵盖旧版迁移、来源与进度保留、阶段排序、跨阶段移动、移动后执行顺序、非法归属、备份引用校验、结构化导入、嵌套列表和代码、目标替换确认。

独立浏览器模拟验证：总目标、阶段分组、当前阶段、导入两个阶段并保留原目标、移动当前步骤后导航同步更新。发现并修复连续跨阶段移动导致目标阶段顺序颠倒的问题。

## 真实 Chrome 验收

1. 重新加载 GuideRail，刷新 ChatGPT 页面，无需重启浏览器。
2. 旧步骤自动出现在“默认阶段”，原进度、问题和关联建议仍在。
3. 在独立验收项目中填写目标，创建两个阶段，移动步骤并调整阶段顺序。当前步骤始终唯一。
4. 查看其他步骤后，当前进度不变化；完成当前步骤后按新顺序推进。
5. 粘贴带阶段标题和编号的建议，核对预览后导入；检查原进度未被覆盖。
6. 关闭后重新打开，目标、阶段和顺序保留；新版备份导出恢复及旧版备份导入正常。

进度百分比仅表示已完成步骤数，不代表实际工作量。所有步骤完成后仍需核对总目标的完成条件。
