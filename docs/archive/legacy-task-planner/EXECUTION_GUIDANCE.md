# 阶段 6 — 执行引导补充规格

用户在阶段 4 验收后明确：原五阶段功能不足以完整解决长建议流失与当前位置失控。经讨论，新增本阶段，并按用户要求将阶段 5、6 合并手动验收。原始 v0.1 规格保留作为历史基线。

## 用户目标

持续回答“整体路线是什么、我现在在哪、当前怎么做、下一步是什么”。

## 已实现的补充范围

- 导航固定展示完成比例、当前序号与标题、下一步及当前未解决问题数量。
- 路线列表独立滚动；选中步骤自动显示在列表中；查看当前操作定位到详情。
- 步骤新增可选 instructions、commands、completionCriteria，兼容既有 notes 和旧备份。
- 详细内容以纯文本显示；命令不自动执行。
- 清单下普通文字归入操作说明，围栏代码块归入命令。支持“操作说明：”“命令：”“完成标准：”标签。保留完整导入原文，不使用模型分析或完整 Markdown 编辑器。
- 推进命令原子完成当前步并切换到按顺序的下一个未完成步骤；略过已完成步骤，遇到阻塞步骤不跳过、不自动解除阻塞。
- 到列表末尾仍有前面的未完成工作时，返回最早的未完成步骤；仅全部完成时报告计划完成。
- 当前步骤含未解决问题时，推进需用户确认，且不自动解决问题。
- 推进时校验当前步骤与下一步预览，阻止重复点击或跨窗口状态变化引起的误推进。
- 同计划关联的所有对话同步更新当前步骤；新增详情进入 JSON 备份校验与恢复。

## 验证边界

单元测试验证领域规则、导入及恢复；模拟数据页面验证窄屏操作、定位、详情编辑及阻塞提示。真实扩展中的下载、重启和真实任务掌控感仍需用户按统一清单验收。
