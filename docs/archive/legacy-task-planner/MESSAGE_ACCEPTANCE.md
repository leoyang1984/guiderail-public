# Phase 1–2 验收

## 已验证

- 自动测试：原子创建步骤并收录、重复关联去重、一源多步骤、显式更新、跨计划误绑拒绝、非法数据拒绝、引用清理、备份往返、v1 迁移及写入失败保留旧数据、来源导航和有界定位失败。
- 独立浏览器模拟页面：默认当前步骤、收录正文和代码、重复收录不重复、多回复归入同一步骤、定位高亮。测试页面使用内存模拟 Chrome API，不读写真实项目。
- 修正宿主 CSS 覆盖 hidden 属性造成的新步骤输入框和快照更新确认错误显示。

## 真实 Chrome 待验收

在扩展管理页重新加载 GuideRail，再刷新 ChatGPT 页面。使用独立验收项目，不以模拟操作修改真实 TTS 进度。

1. 老项目的步骤、状态、问题仍保留；侧栏提示收录入口已连接。
2. 回复生成完成后出现收录入口；生成中无法收录。
3. 连续收录两条回复到一个步骤，再次收录同一条，数量仍为两条。代码块换行正确。
4. 新建步骤并收录，切换对话后收录至明确选定的计划，检查无串绑。
5. 查看原文，分别验证当前对话和另一个对话中的消息。对未加载历史显示失败说明与快照，加载后重试；不跳到相似内容。
6. 编辑或重新生成回复后，重新收录有变化的同 ID 消息必须确认更新；新 ID 视为新来源。验证分支切换下的不可定位提示。
7. 改用途、解除一个引用，其他步骤的引用仍在。关闭侧栏或重启 Chrome 后恢复。
8. 导出新版备份并恢复；在独立验收数据上导入旧版备份，确认旧项目正常且无伪造来源。

消息定位依赖 ChatGPT 当前页面结构；暂不主动滚动加载全部历史，只做约三秒的有界等待与重试。没有匹配 ID 时保留快照，不能视为原文已成功定位。
