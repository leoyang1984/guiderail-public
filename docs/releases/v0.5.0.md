# GuideRail v0.5.0

这一版集中改善收藏与阅读体验，让正文更早出现，并统一明暗主题的排版和颜色。

- 暖纸底色、墨灰正文、苔绿强调色与宋体阅读标题；统一圆角和列表间距。
- 阅读页弱化品牌区并收起常规收藏提示，连接异常及保存状态仍会显示。
- 复制、独立阅读、改标题、删除及导出集中到「更多操作」。按 Esc 收起并恢复焦点，重命名结束后焦点返回按钮。
- 仅在阅读展示中省略与收藏标题完全一致的开头标题；保存、复制、备份及导出的原文完整保留。
- 补充窄栏、宽版、深色、文字对比度和操作流程的自动检查，共 147 项测试通过；类型检查及生产构建通过。

## 安装或更新

下载文件名包含 `chrome` 的 ZIP，解压后在 Chrome 扩展管理页加载解压目录。已安装用户可重新加载扩展，并刷新已打开的 ChatGPT 页面。文件名包含 `source` 的 ZIP 是不含 Git 历史的源码包。

本次使用 DOM 与样式自动检查，未进行浏览器视觉复验或真实目录授权复验。此发布为手动加载的扩展包，不是 Chrome Web Store 上架版本。
