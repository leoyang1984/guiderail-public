# 导出到 Obsidian（v0.4）

1. 更新扩展后，在收藏列表底部展开「导出到 Obsidian」。
2. 点击「选择文件夹」，选择 Obsidian 仓库中的目标目录并允许写入。目录会被记住，界面显示文件夹名称；浏览器不提供完整绝对路径。浏览器再次要求授权时按提示允许即可。
3. 列表页可导出当前列表；切到「全部收藏」可导出全部。进入「管理」勾选后可导出所选；打开一条收藏可单独导出。
4. 若侧栏无法弹出目录选择器，打开一条收藏，点击顶部工具栏的「在新标签页阅读」，在新页面选择文件夹及导出。

每条收藏保存为 `GuideRail-<收藏ID>.md`。标题显示在 YAML 的 `title` 属性中。重命名收藏不会改变文件名。已有同名文件会跳过，不覆盖在 Obsidian 中编辑过的内容；需要新版副本时选择另一文件夹。批量中途失败会显示已完成数量，可重试剩余文件。

Markdown 文件使用 UTF-8，开头是 YAML frontmatter，例如：

```yaml
---
title: "本地 TTS 部署步骤"
source: "https://chatgpt.com/c/example-chat"
conversation_id: "example-chat"
message_id: "example-message"
guiderail_id: "example-bookmark"
role: "assistant"
created: "2026-09-05T12:00:00.000Z"
updated: "2026-09-05T12:00:00.000Z"
exported: "2026-09-05T13:00:00.000Z"
tags:
  - guiderail
  - chatgpt
---
```

`source` 是原对话链接，`message_id` 用于标识具体回复；不把未经验证的消息定位参数拼到链接中。时间为 UTC ISO 8601。正文保留常见标题、列表、表格、引用、链接及代码块；不导出页面按钮、脚本或图片。没有 HTML 快照的旧收藏使用原有文本。

目录设置只保存在本机扩展的 IndexedDB，不包含在 JSON 数据备份中。导出只写入所选目录，不连接 Obsidian 服务。

## 手动验收

- 先在仓库内新建测试文件夹，导出一条含中文标题、列表和代码块的收藏；在 Obsidian 检查属性和正文。
- 在 Obsidian 修改该文件，再次导出同一收藏：应提示跳过，修改应保留。
- 管理中选两条导出，确认只生成所选文件。
- 关闭并重开侧栏：目录名称应恢复，导出时如有提示则重新授权。
- 更换目录后导出：新文件应写到新目录。取消选择应保留原目录。
