# 隐私与本地数据

GuideRail 不提供账号、服务器、分析统计或云同步，不调用 AI API。扩展不会自动上传收藏。

## 读取和保存什么

- 内容脚本运行于 `https://chatgpt.com/*`，识别页面中已渲染的消息并添加收藏按钮。
- 点击收藏后，在当前 Chrome 配置的 `chrome.storage.local` 中保存回复正文、用于阅读的 HTML 快照、对话地址、消息及对话 ID、角色和时间。
- 「找当前对话中的长回复」读取已加载的消息并在扩展内显示候选；只有主动收藏才保存。
- 定位原文时打开或复用 ChatGPT 标签页并查找对应消息。ChatGPT 自身的网络请求由其网站处理。
- Obsidian 导出目录的句柄保存在扩展的 IndexedDB 中，写入需用户通过浏览器授权。目录设置不包含在 JSON 备份中。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| `sidePanel` | 打开阅读侧栏 |
| `tabs` | 根据标签页地址识别当前对话，打开或切换来源对话及独立阅读页 |
| `storage` | 本地保存收藏和兼容数据 |

没有远程采集端点。导出文件包含原对话链接和回复内容，分享这些文件前请自行检查。代码仓库不应收录个人收藏、JSON 备份或导出笔记。

## 删除和备份

可以删除所选收藏或清空全部本地数据。恢复 JSON 备份会替换当前数据，不会合并；恢复前建议先备份。当前完整数据校验上限为 5 MB。

卸载扩展会清除扩展本地数据。已导出的文件仍保留在所选文件夹中，不会随卸载或删除收藏而删除。目录授权可通过浏览器管理。

早期任务管理数据仍保留兼容支持，可能随 JSON 备份一起导出。GuideRail 不提供加密保管功能；本机文件与浏览器配置的访问保护由操作系统和浏览器负责。
